## 🌟 Особенности

* **Zero Dependencies** — построен исключительно на системных библиотеках `user32.lib` и `gdi32.lib`. Никаких громоздких фреймворков (Qt, Electron или .NET).
* **Double Buffering** — отрисовка через виртуальный контекст памяти GDI исключает мерцание окна при перемещении мыши и смене активных элементов.
* **Фирменная палитра Steam**:
  * Фон шапки: `#171A21`
  * Основная область: `#1B2838`
  * Сайдбар библиотеки: `#121418`
  * Акцентные кнопки: `#5C7E10` / `#759C16`
* **Интерактивность**:
  * Динамическое переключение игр в левом сайдбаре.
  * Плавный hover-эффект кнопки «ИГРАТЬ».
  * Информационные карточки с учётом наигранного времени и статуса.
* **Cloud Compilation** — полностью автоматизированный пайплайн сборки MSVC в GitHub Actions.
